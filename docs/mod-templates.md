# Choose a mod template
Choose which type of mod you want to create. Check out the requirements for each mod before creating your spritesheets and assets.

If this is your first time, I would recommend starting with a single Decoration Mod as this is the quickest and easiest item to add to the game.

## Templates:

### :jack_o_lantern: [Create Decoration Mod](docs/templates/create-decoration-mod.md) (easy)
Add a single decoration item to the shop. (ie: a building, tree, statue, etc)

### :four_leaf_clover: [Create Plant Decoration Mod](docs/templates/create-plant-decoration-mod.md) (easy)
Add a single plant decoration item to the shop.
Plant decorations have 4 stages and produce food when they are ready - I've also used this for things like a beehive that produces honey

### :palm_tree::postbox::bath: [Create Decoration Mod Pack](docs/templates/create-decoration-mod-pack.md) (medium)
Add as many decoration items to the shop as you want, in one mod. Can be a combination of standard decorations and plants.

### :milky_way: [Create Background Mod](docs/templates/create-background-mod.md) (easy)
Add a single background to the shop.

### :frog: [Create Animal Mod](docs/templates/create-animal-mod.md) (hard)
Add a single animal to the game.
This requires a lot of work in terms of all the animations you need to create sprites for and there is a little bit more setup on Godot than my other templates.
